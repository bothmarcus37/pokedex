# Pokédex interactiva

Explorador de Pokémon que consume [PokeAPI](https://pokeapi.co/) con `fetch()`.

## Qué hace
- Lista los Pokémon de 24 en 24, con botón para cargar más.
- Filtra por tipo pidiendo a la API todos los Pokémon de ese tipo.
- Busca por nombre o número (acepta `pikachu`, `25` o `#025`).
- Abre una ficha con descripción en español, altura, peso, experiencia base, tasa de captura, habilidades y estadísticas.
- Tipos y estadísticas traducidos al español.

## Cómo ejecutarlo
Copia la carpeta a `htdocs` de XAMPP, inicia Apache y abre `http://localhost/pokemon/`. No necesita base de datos ni claves.

## Hecho con
PHP (configuración de la página), HTML, CSS y JavaScript.
